# FRAME

PinFrames is a private, single-feed Pinterest image viewer. A collector runs on a signed-in desktop; the hosted website reads the synced feed from MongoDB. Website visitors do not create accounts, but each browser needs the private feed token.

## Local dependencies

From this folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
```

## Render and Atlas

1. Push the contents of `FRAME` to a GitHub repository. `app.py` and `render.yaml` should be at the repository root. If FRAME is a subfolder in the repository, set Render's Root Directory to `FRAME`.
2. In Render, create a Blueprint from that repository. It reads `render.yaml` and creates the PinFrames web service.
3. In the Render service environment, set `MONGODB_URI` to the Atlas Python-driver SRV connection string. Keep the URI private. `MONGODB_DATABASE` defaults to `pinframes`; `FEED_TOKEN` is generated by Render.
4. In Atlas Network Access, allow the Render service's outbound IP ranges to reach the cluster. Prefer the listed Render ranges; avoid `0.0.0.0/0` where possible.
5. Deploy. Render serves the viewer and API from the same URL. `/api/health` is the service health check.

The app creates the `personal_feed` collection automatically. The database stores ordered image URLs, the refresh age, and the last successful scrape time.

## Connect a browser

Open the Render URL and choose **Feed key**. Copy the generated `FEED_TOKEN` from Render's environment settings into the dialog. It is saved only in that browser's local storage. Repeat on each browser/device. Do not put the token in a URL, Git, or a public screenshot.

## Run the collector

The collector must run on a desktop where you can sign into Pinterest. It uploads image URLs to Render; it does not send Pinterest passwords or browser cookies.

Create a private `.env` file in FRAME (it is git-ignored):

```dotenv
PINFRAMES_API_URL=https://YOUR-RENDER-SERVICE.onrender.com
PINFRAMES_FEED_TOKEN=YOUR_PRIVATE_FEED_TOKEN
```

Load the variables in a terminal from FRAME:

```bash
set -a
source .env
set +a
```

For the first scrape, sign in visibly and keep the Pinterest window open until completion:

```bash
./.venv/bin/python scrape_homefeed.py --headed
```

On later starts, run:

```bash
./.venv/bin/python scrape_homefeed.py
```

The collector checks the shared refresh age and skips a fresh feed. Use `--force` to scrape regardless of age. Set this command to run at login on the collector computer if you want the startup check to happen automatically. The browser profile stays on that computer; only image URLs are uploaded.

The viewer advances in order and removes each displayed URL from MongoDB. Rotation interval, background color, and refresh age are saved with the shared feed settings and apply on other devices; the private feed token remains stored only in each browser. The viewer starts in an immersive full-viewport layout, with the controls revealed by pointer movement or a touch. Browsers that do not permit native fullscreen on page load use this immersive layout instead. **Delete saved links** clears the cloud feed. **Scrape again** explains how to run the collector because a hosted website cannot launch a process on your computer.

## Local mode

Without `PINFRAMES_API_URL` and `PINFRAMES_FEED_TOKEN`, `server.py` remains available for local file-backed development:

```bash
./.venv/bin/python server.py
```

Open <http://127.0.0.1:8000/>.
